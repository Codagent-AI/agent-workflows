# agent-workflows

## 0.1.0

### Minor Changes

- First release. One version covers the whole repository.
- `define-openspec-change`, a Claude Code and Codex plugin that defines an OpenSpec change step by step in your own session: proposal, specs, design, test plan, and approach review, with a cross-vendor review. It ships a bundled MCP server that runs on Node.js 22 or later.
- `codagent-archon`, a Claude Code and Codex plugin that implements an approved OpenSpec change with the Codagent pack on Archon and follows the run to the end.
- The Codagent pack of factory workflows for the Archon engine. Each release attaches it as `agent-workflows-pack_<version>.tar.gz`, with a `checksums.txt`.
- The repository root is a plugin marketplace for Claude Code and Codex.
